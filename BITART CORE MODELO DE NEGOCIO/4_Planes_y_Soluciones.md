# Estructura de Planes y Soluciones (Enfoque Marca Blanca y SaaS)

Para alinear la sección de precios con la estrategia de "Desarrollar una vez, vender múltiples veces" (Plantilla BitartCore) y atraer clientes de alto valor, debemos cambiar el enfoque de los planes.

En lugar de vender "Sitios web", vamos a vender **"Soluciones de Negocio"**. 

Aquí tienes la propuesta exacta para los textos de las 3 tarjetas de precios:

---

## Tarjeta 1: Landing Page Avanzada (El Gancho)
*Esta es la entrada para clientes más pequeños o campañas rápidas. Requiere cero tiempo de arquitectura y se hace rapidísimo.*

*   **Título:** Landing Page Avanzada
*   **Subtítulo:** Ideal para validar productos, captación de leads o campañas específicas.
*   **Setup Inicial:** Desde $800.000 COP
*   **Suscripción Mensual:** $90.000 COP / mes
*   **Características (Bullets):**
    *   Diseño UI/UX de alta conversión (Efecto WOW).
    *   Integración de embudos con WhatsApp o CRMs externos.
    *   Optimización de velocidad estricta (Core Web Vitals).
*   **Términos de la Suscripción ($90.000 COP/mes):**
    *   *Incluye: Alojamiento en servidor rápido, Certificado SSL y 1 hora de soporte para cambios menores de texto o imágenes.*
*   **Llamado a la acción (Botón):** Iniciar Proyecto

---

## Tarjeta 2: Portal B2B / E-commerce (El Producto Estrella Replicable) - **MÁS POPULAR**
*Aquí es donde entra el modelo de **Marca Blanca**. Este plan no se programa desde cero. Usarán el "BitartCore Template" que ya tiene login, pagos y base de datos configurados. Solo le cambiarán el diseño y colores a cada cliente/agencia.*

*   **Título:** Portales y E-commerce
*   **Subtítulo:** Plataformas autogestionables para digitalizar las operaciones de tu empresa.
*   **Setup Inicial:** Desde $2.500.000 COP
*   **Suscripción Mensual:** $250.000 COP / mes
*   **Características (Bullets):**
    *   Panel de Administración y gestión de roles (Identity).
    *   Catálogo de ventas o Gestión de Clientes (CRM base).
    *   Integración nativa con pasarelas de pago.
    *   Infraestructura escalable a nivel empresarial.
*   **Términos de la Suscripción ($250.000 COP/mes):**
    *   *Incluye: Alojamiento en Servidor Dedicado/Cloud, Copias de seguridad diarias (Backups) y Soporte técnico garantizado ante caídas (SLA).*
*   **Llamado a la acción (Botón):** Cotizar Plataforma

---

## Tarjeta 3: Software Personalizable (Proyectos de Alto Valor)
*Este es para Startups, desarrollo de SaaS propio de un cliente, o integraciones móviles pesadas.*

*   **Título:** SaaS, Apps & 3D
*   **Subtítulo:** Construimos el núcleo tecnológico de tu empresa a medida.
*   **Setup Inicial:** Consultar (Ticket Alto)
*   **Suscripción Mensual:** Retainer Personalizado
*   **Características (Bullets):**
    *   Arquitectura Multi-tenant y Cloud (Azure/AWS).
    *   Desarrollo Multiplataforma (Web y Móvil nativo).
    *   Integración avanzada con Inteligencia Artificial.
    *   Experiencias 3D interactivas y Gamificación (WebGL).
    *   Seguridad empresarial y bases de datos robustas (.NET).
*   **Términos de la Suscripción (Retainer Personalizado):**
    *   *Incluye: Arquitectura Cloud Empresarial, Soporte técnico de máxima prioridad y Bolsa de horas asignadas para Desarrollo Evolutivo (Nuevas funciones).*
*   **Llamado a la acción (Botón):** Agendar Consultoría

---

### ¿Por qué esta estructura es mejor?
1. **Reduce tu tiempo de desarrollo:** El Plan 2 (El más vendido) será siempre una clonación de su plantilla base en .NET. Tardarán una fracción del tiempo en entregarlo.
2. **Filtra a los clientes:** Quien busca algo de $300.000 pesos huirá, lo cual es excelente porque esos clientes consumen mucho tiempo y no dejan ganancia.
3. **Ingresos Recurrentes (MRR):** Obliga a integrar las mensualidades visualmente para que el cliente entienda que compra un servicio vivo, no solo un código estático.
