# Políticas de Cobro: El "Setup Inicial"

Una regla vital para proteger la rentabilidad y el tiempo del equipo de desarrollo de BitartCore es manejar correctamente el concepto de **"Desde"** en los precios de instalación (Setup Inicial).

## 1. ¿El precio del Setup es fijo?
Sí, **PERO** solo bajo condiciones estrictas.

En nuestras tarjetas de precios escribimos **"Desde $2.500.000"** (por ejemplo, para el Portal B2B) por una razón estratégica muy específica:

*   **Es Precio Fijo ($2.500.000):** SI el cliente se acopla al 100% a la "Plantilla BitartCore". Es decir, si lo único que el equipo de desarrollo debe hacer es instalar la plantilla, cambiar el logo, ajustar los colores corporativos (tematización CSS) y cargar la información inicial (ej: subir 10 productos o crear los primeros usuarios).
*   **Es Precio Variable (Aumenta):** SI el cliente exige personalizaciones que rompen el molde de la plantilla. Por ejemplo: *"Quiero este portal B2B, pero necesito que el formulario de registro se conecte con el sistema contable de la empresa mediante una API personalizada"*. En este escenario, el precio base de $2.500.000 se mantiene, y se le suma el costo de las horas de desarrollo extra. (Ejemplo: $2.500.000 Base + $1.500.000 Integración Especial = **$4.000.000 Total**).

## 2. El Escudo Comercial del "Desde"
Usar la palabra **"Desde"** actúa como un escudo comercial:
1.  **Enganche:** Atrae al cliente con un precio de entrada altamente competitivo.
2.  **Filtro:** Te da la total libertad y autoridad para subir el costo del Setup Inicial durante la reunión de ventas si notas que el cliente es complicado, tiene requerimientos pesados o exige funcionalidades que tomarán días adicionales de código.

## 3. La Mensualidad es Inamovible
Es importante recalcar al cliente que sin importar si su Setup costó $2.500.000 o $5.000.000 (por las personalizaciones extra), **su suscripción mensual ($250.000) se mantiene fija** (ya que el consumo del servidor cloud sigue siendo similar). Esto les da seguridad a ellos de que no les subirán la mensualidad sorpresa, y garantiza el ingreso recurrente estable para BitartCore.
